# OLA Ride Analytics Dashboard

## Project Overview

This project analyzes OLA ride booking data using SQL and Power BI to generate business insights. The dashboard provides interactive visualizations for booking trends, revenue analysis, vehicle performance, cancellation analysis, and customer/driver ratings.

---

## Tools & Technologies

- SQL (MySQL)
- Power BI
- Data Visualization
- Dashboard Design

---

## Dashboard Pages

### 1. Overall Dashboard
- Total Bookings
- Total Booking Value
- Booking Status Breakdown
- Daily Booking Trend

### 2. Vehicle Type Analysis
- Booking Value by Vehicle
- Successful Booking Value
- Average Ride Distance
- Total Distance Travelled

### 3. Revenue Dashboard
- Revenue by Payment Method
- Daily Revenue Trend
- Top 5 Customers

### 4. Cancellation Dashboard
- Successful Bookings
- Cancelled Bookings
- Cancellation Rate
- Customer Cancellation Reasons
- Driver Cancellation Reasons

### 5. Ratings Dashboard
- Driver Ratings by Vehicle Type
- Customer Ratings by Vehicle Type

---

## SQL Analysis

The project includes SQL queries to analyze:

- Successful bookings
- Average ride distance
- Customer cancellations
- Driver cancellations
- Top customers
- UPI payments
- Booking value
- Customer ratings
- Driver ratings
- Incomplete rides

---

## Key Insights

- More than 103K ride bookings analyzed.
- Total booking value reached approximately 35M.
- Success rate around 62%.
- Cash and UPI were the most preferred payment methods.
- Vehicle-wise performance and customer satisfaction were analyzed.
- Customer and driver cancellation reasons were identified.
